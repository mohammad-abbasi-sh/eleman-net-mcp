# eleman-net-mcp 🇹🇷

mcp-name: io.github.mohammad-abbasi-sh/eleman-net-mcp

سرور MCP غیررسمی و **فقط-خواندنی** برای eleman.net، سایت کاریابی یقه‌آبی ترکیه (رتبهٔ ۲ دستهٔ مشاغل ترکیه، ‎~۴٫۴ تا ۵٫۱ میلیون بازدید در ماه طبق SimilarWeb) — جست‌وجوی شغل بر اساس سمت یا شهر، خواندن جزئیات کامل آگهی، فهرست هر ۹۳ بخش و هر ۸۱ استان، و دریافت تازه‌ترین آگهی‌ها.

> ساخته‌شده توسط محمد عباسی در چارچوب «کارخانهٔ MCP ترکیه» (خط تولید به سبک سپهر). وابسته به eleman.net نیست.

## برای ایجنت‌های هوش مصنوعی

به پیکربندی MCP client خود اضافه کنید (stdio):

```json
{
  "mcpServers": {
    "eleman-net": {
      "command": "uvx",
      "args": ["eleman-net-mcp==0.1.1"]
    }
  }
}
```

یا به‌صورت محلی اجرا کنید: `python -m eleman_net_mcp.server` (نیازمند `mcp<2` و `curl-cffi`).

## ابزارها

| ابزار | توضیح |
|------|-------|
| `eleman_search_jobs` | جست‌وجوی شغل — `keyword` (سمت، مثلاً «garson»، «şoför»، «muhasebe»)، `city` (مثلاً «İstanbul»، «Ankara»)، `page` از ۱، `limit` ۱ تا ۳۰؛ آگهی‌ها (شناسه، عنوان، شرکت، مکان، خلاصه، URL) + صفحه‌بندی (۱۹۷ صفحه در ۲۰۲۶-۱۱-۰۷) |
| `eleman_get_job` | جزئیات کامل یک آگهی — `job_url` (نشانی `…/is-ilani/<slug>-i<id>` از نتیجهٔ جست‌وجو)؛ عنوان، تاریخ انتشار، نوع اشتغال، توضیح کامل، شرکت (+ URL)، مکان، منطقه، شرایط تحصیلی |
| `eleman_list_sectors` | هر ۹۳ بخش شغلی eleman.net (نام + شناسهٔ بخش)، از نوار کناری خود سایت |
| `eleman_list_cities` | هر ۸۱ استان ترکیه (+ دو سمت استانبول) با URL فهرست eleman.net برای هر یک |
| `eleman_new_listings` | تازه‌ترین آگهی‌ها (صفحهٔ اول، از جدید به قدیم)، `limit` ۱ تا ۳۰ |

خروجی نمونه (`eleman_search_jobs` / «garson»):

```json
{"keyword": "garson", "count": 2, "jobs": [
  {"title": "Garson", "company": "TAVUK DÜNYASI",
   "location": "İstanbul Anadolu - Ataşehir",
   "url": "https://www.eleman.net/is-ilani/…"}, …]}
```

## نحوهٔ کار

eleman.net آگهی‌ها را کاملاً سمت سرور رندر می‌کند — بدون ورود، کلید API و کوکی نشست. هر صفحهٔ فهرست ۳۰ کارت شغلی دارد (بلوک‌های `ilan_id_<id>`: عنوان، شرکت، «شهر - ناحیه»، خلاصه؛ آگهی‌های فوری نشان «ACİL İLAN» در بلوک عنوان دارند و بعضی کارت‌ها پیش از توضیح، برچسب مزایا دارند — تجزیه‌کننده هر دو را مدیریت می‌کند). صفحه‌های سمت و شهر یک فضای slug مشترک دارند (`/is-ilanlari/<slug>`: garson، istanbul، ankara و…)؛ ترکیب شهر + کلیدواژه، slug شهر را با `?aranan=<keyword>&arandi=e` ترکیب می‌کند. صفحه‌های جزئیات آگهی بلوک JobPosting از نوع JSON-LD از schema.org دارند (عنوان، datePosted، توضیح، employmentType، مکان، شرکت). شناسهٔ عددی تنها، URL معتبر جزئیات نیست — نشانی کامل آگهی را از نتیجهٔ جست‌وجو بدهید (slugهای ناشناخته با ۳۰۱ به صفحهٔ اصلی هدایت می‌شوند و تجزیه‌کننده آن را رد می‌کند). انتقال با جعل TLS کروم انجام می‌شود (`curl-cffi`، `chrome120`)؛ درخواست‌ها با فاصلهٔ ‎~۰٫۸ ثانیه فرستاده می‌شوند؛ همه‌چیز فقط-خواندنی است.

توجه: جست‌وجوی `/ara` خود سایت و جست‌وجوی انجمن نیازمند توکن‌اند؛ پس جست‌وجوی کلیدواژه از مسیرهای slug/پارامتر بالا که به‌صورت زنده تأیید شده‌اند استفاده می‌کند. نقطهٔ پایانی تکمیل خودکار (`/arama_complete.php`) در robots.txt ممنوع است و استفاده نمی‌شود.

## نصب

```bash
uvx eleman-net-mcp==0.1.1        # اجرای مستقیم (نیازمند uv)
# یا
pip install eleman-net-mcp==0.1.1
eleman-net-mcp    # سرور MCP را روی stdio راه می‌اندازد
```

## تست‌ها

```bash
python -m venv .venv && .venv/bin/pip install -e .
.venv/bin/python -m unittest discover -s tests -v
```

تست‌های آفلاین روی صفحات ضبط‌شده اجرا می‌شوند (صفحات واقعی دریافت‌شده در ۲۰۲۶-۱۱-۰۷)؛ تست‌های زنده به eleman.net وصل می‌شوند. در زمان ساخت ۲۸ از ۲۸ سبز بود (۱۵ آفلاین + ۱۳ زنده) به‌همراه یک تست دود MCP روی stdio.

## نقشهٔ راه

- جست‌وجوی فیلترشده بر اساس بخش (فیلتر `?sek[]=<id>`)
- صفحه‌های شرکت (`/firma/<slug>`: آگهی‌ها + پروفایل شرکت)
- اطلاعات حقوق در جاهایی که سایت منتشر می‌کند (در دادهٔ JobPosting نادر است)
